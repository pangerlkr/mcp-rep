# User Guide - MCP Server Builder Platform

## Quick Start

This guide will help you build and deploy your first MCP server in minutes.

### Step 1: Select Integrations

1. Browse the available MCP integrations on the homepage
2. Use category filters to find what you need
3. Click "Select" on each integration you want to include

### Step 2: Configure Settings

1. Click the ⚙️ icon on integrations that require configuration
2. Fill in required credentials and settings
3. Save your configuration

### Step 3: Build Your Server

1. Click the green "Build Server" button
2. Choose a name and description
3. Select your export format (JSON, Docker, or NPM)
4. Download your configuration

### Step 4: Deploy

Follow the deployment instructions for your chosen format.

## Available Integrations

- **Filesystem**: File and directory access
- **GitHub**: Repository management
- **PostgreSQL/SQLite**: Database operations
- **AWS**: Cloud services
- **Slack**: Team communication
- **Docker**: Container management
- **Puppeteer**: Browser automation
- And more!

## Export Formats

### JSON Configuration
Standard MCP config file ready to use with any MCP client.

### Docker
Complete Dockerfile with all dependencies for containerized deployment.

### NPM Package
package.json file with dependencies and scripts.

## Security Best Practices

1. Never commit API keys to version control
2. Use environment variables for sensitive data
3. Grant minimal required permissions
4. Regularly rotate credentials
5. Monitor access logs
